# Fond de carte OpenStreetMap au lieu de CARTO

- **Problème** : les tuiles CARTO light_all renvoient désormais une image « API KEY REQUIRED » ; les sept cartes étaient vides.
- **Décision** : tuiles OSM standard (`tile.openstreetmap.org`), attribution « contributeurs d'OpenStreetMap », filtre sépia conservé.
- **Pourquoi** : aucune clé, usage modéré admis par la politique d'OSM ; un fond auto-hébergé (Protomaps sur R2) reste la piste si le trafic grandit ou pour un fond dans l'esthétique des planches.
- **Où** : les sept composants Leaflet de src/components (LieuxMap, ExploreMap, MapChrono, MapRoutes, TraverseeMap, CarteBarito, FokoMap).
